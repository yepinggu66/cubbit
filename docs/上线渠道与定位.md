## 一、为什么不是「先上 Steam」

| 渠道 | 审核 | 费用 | 有没有评分 | 适合现在吗 |
|---|---|---|---|---|
| **官网直发（已在线）** | 无 | 0 | 无 | ✅ 今天就能发 |
| **itch.io** | 无（几分钟） | 0 | 有评分但不影响分发 | ✅ 本周补 |
| **Steam 抢先体验** | 1–2 周 | $100（满 $1000 退） | **有，且不可逆** | ⏳ 两周后 |
| Microsoft Store | 1–2 周 + MSIX 打包 | 0 | 有 | ❌ 收益不成正比 |
| GitHub Releases | 无 | 0 | 无 | 可选（开发者信任背书） |

现在最贵的东西是「第一批真实用户数据」，不是「商店页」。Steam 的评分一旦开成「褒贬不一」，后面要花几倍力气拉回来——所以顺序必须是：**先在没有评分的地方把配对跑通，再进 Steam**。

## 四、但「AI」这两个字，现在还不能写

我查了当前这版（2.5.1-soft）的实际状态：

| 事实 | 证据 |
|---|---|
| AI 面板在 Lite 版里**被隐藏**，导航里没有入口 | `shared/nav-layout.js` 的 `LITE_SECTION_IDS` 只有 couple/appearance/interaction/member/about |
| AI 订阅开关是**关的** | `offer-config.js`：`aiCompanion: false` |
| AI 默认接**本地 Ollama**（用户自己装），不填 key 就走规则台词 | `main/ai.js`：默认 `ollama`，`127.0.0.1:11434` |
| 全仓 **0 处** DeepSeek | grep 结果 |

也就是说：现在写「AI 桌面宠物」，用户装完会找不到 AI——这是最典型的一星差评来源（"说好的 AI 呢"）。

**两条路，我建议 A：**

| 方案 | 要做什么 | 工作量 | 成本 | 评价 |
|---|---|---|---|---|
| **A. 把 AI 做真**（推荐） | 服务端加 `/ai/chat` 代理（key 只在服务器）+ 每设备每天 5 次配额 + 客户端内置 DeepSeek 预设并打开 AI 入口 | 我 1 天 | DeepSeek 充值 ¥20 起，40 人两周约 ¥10–30 | 标题立即成立，且「AI 养宠物」是真的卖点 |
| B. 先不写 AI | 标题改「桌面宠物」，AI 上线后再改名 | 0 | 0 | 安全，但少一个搜索入口和记忆点 |
| C. 硬写 | 直接标 AI 卖 | 0 | 0 | ❌ 我不建议：装完找不到 AI，等于自己制造差评 |

方案 A 里我唯一需要你给的，是**一个 DeepSeek API Key**（platform.deepseek.com，充 ¥20 就够跑完内测）。拿到 key 我当天能做完：服务端代理 + 配额 + 客户端入口 + 重新打包 + 上传 + 我这边先跑通对话链路。
