# 反馈表单（10 题 · 中英双语）

> **用途**：两周内测结束时发给参与者的回收问卷，10 题、全部单选/多选/一行填空，填完约 3 分钟；中英双语并列，直接粘进 Google Forms、腾讯问卷或飞书问卷都能用。

---

## 使用说明

- **什么时候发**：第 14 天，统一发一次；第 16 天补发一次提醒（只说「还差你一份，两分钟」）。
- **发给谁**：问卷开头先问称呼/配对日期，方便对上号；不要让他们填安装 ID（他们找不到）。
- **怎么收**：Google Forms（英文用户）或腾讯问卷/飞书（中文用户）各建一份，题干用本文件原样粘贴；也可以直接微信/邮件发正文让对方按编号回答。
- **配套材料**：愿意的话让他们附上 `%APPDATA%\Cubbit\beta-events.jsonl`（两台机器都发）——只含事件和安装 ID，不含聊天内容。
- **回收后重点看**：Q2 配对成功率、Q4 双人同日天数、Q9 付费意愿；这三题决定「继续做 / 先修 / 停」。

## 附：这 10 题各自在测什么（内部用，别发给用户）

| 题 | 测的是什么 | 判读方式 |
|---|---|---|
| Q1 | 兼容性分层 | Win10 用户占比高不高，决定要不要继续保 Win10 |
| Q2 | 配对成功率 | 核心门槛：低于 8/10 就先修配对，不扩招 |
| Q3 | 配对摩擦 | 超过 5 分钟＝自助流程不合格，需要扫码/链接配对 |
| Q4 | 双人同日天数 | 情侣产品真正的留存指标；低于 40% 说明「双人联动」不是刚需 |
| Q5 | 真实使用面 | 看「戳一戳 / 手势 / 传话」是不是真的在用，还是只挂着好看 |
| Q6 | 该砍的功能 | 连续两批都被选「没用」的，下一版直接下掉 |
| Q7 | 稳定性 | 「消息收不到」出现率决定能不能对外说「可用」 |
| Q8 | 推荐意愿 | 7 分以上才有口碑传播，情侣产品靠一对带一对 |
| Q9 | 付费意愿 | 明确「一定买」≥ 5/10 才值得做正式版的收费链路 |
| Q10 | 可召回人群 | 决定正式版发布时有没有第一批种子用户 |
